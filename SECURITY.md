# Security

This is a failure-testing tool, not a production pricing or lending system. Keep the developer API on loopback; Host and Origin checks are not authentication. Corpus input, claimed provenance and reference reports are untrusted. No provider signatures or reference-source independence are verified. The mock contract administrator can supply arbitrary reports by design. Do not use its outputs to manage funds. Report vulnerabilities through GitHub private security reporting if available, otherwise describe impact without secrets in an issue.
